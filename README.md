# 電阻計算

集中繞馬達繞組的電阻計算工具，單一 HTML 檔，直接在瀏覽器執行。

**線上使用：** https://siderpan.github.io/winding-resistance-calculator/

## 功能

- 馬達模型參數：可命名儲存於本機瀏覽器（外轉／內轉各自分開），並可匯出／匯入 Excel 檔（含參數表與計算結果）

- 頁首可切換「外轉式馬達」與「內轉式馬達」，兩種各自保留輸入值（網址加 `#inner` 直接開內轉式）

- 輸入定子齒部疊厚、齒寬、可繞線長度 l_w、軛部圓弧半徑、槽數、定子內外徑、槽開口，以及絕緣厚度、側視轉角與槽內 R 角
- 依導線完成外徑、匝數、並繞股數與排線方式（整齊方格／正交嵌入、鬆散係數），即時畫出導線逐層排列的槽空間排線圖、側視圖與定子全圖
- 逐層計算每匝周長並累加總線長，求出平均匝長 MLT，並與簡化公式比較
- 檢查線圈厚度是否超過可用上限、繞線窗口佔積率
- 由線長算出線圈、相電阻與 Y／Δ 端子間電阻，含溫度修正

## 計算式

```
L' = L + 2i      b' = b + 2i
第 k 層中心距絕緣面  c_k = d_o/2 + k·p_r
整齊方格 p_r = g·d_o      正交嵌入 p_r = 0.866·g·d_o
每匝長  ℓ_k = 2(L'−2r₀) + 2(b'−2r₀) + 2π(r₀ + c_k)
每股線長 = Σ(ℓ_k × 該層根數) ÷ n_s
MLT = 每股線長 ÷ N
R_coil = ρ · 每股線長 / (A · n_s)
R_ph = [R_coil · 線圈數/a + ρ·引出線/(A·n_s)] / a
Y：R_LL = 2·R_ph      Δ：R_LL = ⅔·R_ph
R(T) = R₂₀ · (234.5+T) / 254.5
```
