# 馬達繞組電阻速算

設計階段用的三相馬達繞組電阻估算工具，單一 HTML 檔，直接在瀏覽器執行。

**線上使用：** https://siderpan.github.io/winding-resistance-calculator/

## 功能

- 由線徑（或 AWG）、並繞股數、匝數、每相線圈數、並聯路數估算相電阻
- 平均匝長 MLT：集中繞可由齒部幾何（疊厚、齒寬、絕緣厚、線圈堆疊厚）估算，或直接輸入
- Y／Δ 接線換算端子間電阻 R<sub>LL</sub>（三用電表實際量到的值）
- 銅線溫度修正，互動式溫度–電阻曲線與對照表
- 電流密度、銅損、銅重
- 電阻法反算繞組平均溫度與溫升（IEC 60034-1）

## 計算式

```
A     = π/4 · d²
ℓpath = N · (線圈數/a) · MLT + 引出線
Rph   = ρ · ℓpath / (A · ns · a)
R(T)  = R20 · (234.5 + T) / 254.5
Y : RLL = 2·Rph      Iph = IL
Δ : RLL = ⅔·Rph      Iph = IL/√3
PCu   = 3·Iph²·Rph = 1.5·IL²·RLL
```

## 注意

估算值通常比實測略低：漆包線實際電阻率常偏高 1–3%，繞線張力會拉細導線，另有焊點與端子接觸電阻。量到第一顆樣品後，可用頁面中「實測反算」的比例回頭校正電阻率或 MLT。
