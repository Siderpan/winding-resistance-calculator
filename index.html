計算明細

    逐層線長

    計算式 
    L' = L + 2i     b' = b + 2i
第 k 層中心距絕緣面 c_k = d_o/2 + k·p_r
整齊方格 p_r = g·d_o   正交嵌入 p_r = 0.866·g·d_o
每層可排根數 n = ⌊(h − d_o)/(g·d_o)⌋ + 1（正交奇數層 n−1）
每匝長 ℓ_k = 2(L'−2r₀) + 2(b'−2r₀) + 2π(r₀ + c_k)
每股線長 = Σ(ℓ_k × 該層根數) ÷ n_s
MLT = 每股線長 ÷ N
R_coil = ρ · 每股線長 / (A · n_s)
R_ph = [R_coil · 線圈數/a + ρ·引出線/(A·n_s)] / a
Y：R_LL = 2·R_ph    Δ：R_LL = ⅔·R_ph
R(T) = R₂₀ · (234.5+T)/254.5
